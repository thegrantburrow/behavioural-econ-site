# Review HTML (feedback pages)

Interactive oscarfinch feedback pages live here. Each file is a full HTML
review with Looks good / Needs work per card and a copyable feedback panel.

## How to open one

After it is pushed to GitHub, use htmlpreview (runs the JS):

```
https://htmlpreview.github.io/?https://raw.githubusercontent.com/thegrantburrow/behavioural-econ-site/<branch>/mockup/reviews/<file>.html
```

Example (product-risk principles draft):

https://htmlpreview.github.io/?https://raw.githubusercontent.com/thegrantburrow/behavioural-econ-site/cursor/lineup-risk-principles-review-96ff/mockup/reviews/lineup-risk-principles-review.html

Agents must put that link in the **parent** chat reply. Nested computer-use
transcripts are not a delivery channel.
